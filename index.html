RaktSetu

A BCA (AI) mini project — a real-time donor availability finder, built to replace outdated donor lists with donors who can confirm they're actually available.

This is a front-end demo: donor data lives in the browser only. Connect a real database (Firebase / MongoDB / Supabase) and add login so each donor controls only their own status.
